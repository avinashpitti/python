4.Identifiers :
Identifiers are the names used to identify a variable, function,
class, module or other object.

In short, Anything you name in python is identifier.

Rules for Identifiers
1. Identifiers should start with a letter or an underscore (_).
2. Identifiers can only contain letters, digits, and underscores.
3. Identifiers are case-sensitive.
4. Identifiers should be descriptive and meaningful.
5. Identifiers should not be reserved keywords.
6. Naming conventions:
    snake_case for variables and functions
    PascalCase for classes
    uppercase for constants

9. Mutable vs Immutable
A mutable object is an object whose value or state can be changed after it is created.
nums = [1, 2, 3]
nums.append(4)
Mutable types :
list,dict,set,bytearray

An immutable object is an object whose value or state cannot be changed after it is created.
x = 10
x = 20
Here 10 is not modified, A new object 20 is created and 'x' now refers to it.
Immutable types :
int,float,complex,bool,str,tuple,frozenset,bytes,NoneType

14. What is shallow copy?
A shallow copy creates a new outer object
But inner objects still share same memory
a=[[1,2],[3,4]]
b=a.copy()
print(id(a))
print(id(b))

a ---->  [  ----> [1,2]   ----> [3,4]  ]
b ---->  [  ----> [1,2]   ----> [3,4]  ]
outer list is new
But inner list is still same
a[0].append(99) # you modified the inner list, so both see the change
print(a)
print(b)


15. Ways to create a shallow copy?
b = a.copy()
b = list(a)
b = a[:]
These all are shallow copies


16. What is deepcopy?
deepcopy creates new outer object

completely independent

print(a)
print(b)
